# LINVISUALS

Готовый статический сайт для публикации через GitHub Pages.

## Запуск через GitHub

1. Создай новый репозиторий на https://github.com/new
2. Назови его, например, `linvisuals-site`.
3. Загрузи в репозиторий **все файлы из этой папки**. В корне репозитория должен лежать `index.html`.
4. Открой в репозитории **Settings → Pages**.
5. В разделе **Build and deployment** выбери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Нажми **Save** и подожди завершения публикации.
7. Адрес сайта появится в разделе **Settings → Pages**.

## Важно

- Главная страница находится в `index.html`.
- Сайт статический: сервер или сборка не нужны.
- Перед публикацией проверь ссылки на скачивание и Discord, а также актуальность информации о версиях.
- GitHub Pages публикует содержимое репозитория публично, если репозиторий публичный.
